# Дополнительно (расширенные настройки)

← [На главную](Home.md)

Вкладка **Дополнительно** — для тех, кому нужен полный контроль. Большинству
пользователей сюда заходить не нужно: всё необходимое есть на «Главной».

## Основное

- **Режим маршрутизации:**
  - *Через VPN только заблокированное (рекомендуется)* — через туннель идут только
    списки заблокированного/зарубежного, остальное напрямую.
  - *Всё через VPN, исключения — напрямую* — по умолчанию всё в туннель, а список
    «напрямую» — исключения.
  - *Через VPN только выбранные списки/домены* — в туннель идёт только то, что вы
    явно указали.
- **Интервал проверки (сек)** — как часто проверять туннели и переключаться при
  сбое.
- **Блокировать трафик, если туннель недоступен** (kill switch) — не выпускать
  трафик в обход VPN, когда все туннели мертвы.
- **LAN-интерфейс / подсеть**, адреса проверки связи — обычно определяются сами.

## Туннели (с приоритетом)

Список туннелей с номерами приоритета: меньший номер — выше. Если первый отвалится,
splify переключится на следующий. Здесь же выбирается **тип** туннеля
(`WireGuard / AmneziaWG`; `sing-box` — [в планах](sing-box.md)).

## Списки

URL-адреса списков заблокированных/прямых IP и доменов, переключатель **zapret**
(обход DPI). Значения по умолчанию рабочие — меняйте, только если знаете зачем.

## FACEIT (обход блокировок игры)

Отдельный переключатель под списками. Чинит подключение к FACEIT/CS2 на
DPI-блокировках (ТСПУ — Ростелеком и др.) с **минимальным оверхедом на пинг** —
это роутерный аналог пресета `complex multidisorder (game filter)`.

**Как это работает:** splify запускает **свой собственный nfqws** на отдельном
`qnum=192` (не полагаясь на nfqws от zapret'а). Трафик к IP-адресам хостеров
FACEIT (UDP 27015-27036 — геймплей, TCP 443/27015-27030 — лобби и API)
заворачивается в этот nfqws только на handshake-пакетах, после чего поток
отпускается — поэтому сам геймплей идёт почти без задержек. Если nfqws не
установлен или упал — трафик идёт напрямую без изменений (`bypass`), матч не
рвётся.

**Что настраивать:**
- **Хостеры** — у FACEIT нет своего ASN, серверы арендуются у OVH / Hetzner /
  Google Cloud / i3D.net. Все четыре включены по умолчанию; отключайте только
  если уверены, что ваш регион их не использует.
- **UDP / TCP cutoff** — после какого пакета отпустить поток. `d2` (по умолчанию
  для UDP) = минимальный оверхед, лучший пинг. Если подключение не
  устанавливается на жёстком DPI — поднимайте до `n2`/`n3`.
- **repeats** — сколько фейков посылать. `1` = минимум (UDP по умолчанию),
  `10` = максимум надёжности (ценой всплеска на handshake).
- **Путь к fake bin** — пусто = zero-filled default (не требует файла). Для
  агрессивных DPI можно указать путь к zapret'овскому bin, например
  `/opt/zapret/files/fake/quic_initial_dbankcloud_ru.bin`.

### Про точность списка (важно)

Список хостеров — **не FACEIT-специфичный**. FACEIT не публикует свои IP, поэтому
splify использует диапазоны самих хостеров целиком: ~4.6 млн адресов OVH (весь
AS16276), ~3.4 млн Hetzner, ~19 млн Google Cloud (по официальной ленте
`gstatic.com/ipranges/cloud.json`), плюс i3D geofeed. FACEIT — лишь небольшое
подмножество в этих миллионах.

Практически это безопасно: nft-правило матчит только порты UDP 27015-27036 и
TCP {443, 27015-27030}, а они почти полностью заняты Source/Steam-серверами.
Не-FACEIT трафик к этим IP просто получит fake-desync на handshake (соединение
всё равно установится, а `bypass` флаг гарантирует, что при падении демона
ничего не дропнется).

### Ручные IP-переопределения

Файл **`/etc/splify/faceit-user.lst`** — ваш operator-owned список, который
**никогда не перезаписывается** обновлениями splify или cron'ом, а мерджится
поверх списка хостеров при каждом обновлении. Формат: одно IPv4/CIDR на строку,
`#`-комментарии разрешены, некорректные строки тихо отбрасываются.

Когда это нужно:
1. IP вашего FACEIT-сервера ещё не попал в BGP-список хостера (узнайте его
   командой `status` в консоли CS2 → поле `udp/ip`), добавьте как `/32`.
2. FACEIT использует хостера, которого нет в списке (OVH/Hetzner/GCP/i3D).
3. Вы хотите **сузить collateral** — отключите лишних хостеров в LuCI и держите
   только нужные `/32` здесь.

Путь к файлу можно переопределить UCI-опцией `faceit_user_file`.

**Требования:** установленный zapret/nfqws (`opkg install zapret` или пакет
`remittor/zapret-openwrt`). До этого сервис просто тихо бездействует.

Списки IP хостеров обновляются автоматически раз в сутки (cron 04:35).

## Ручные записи

Свои подсети и домены: что гнать через VPN, а что напрямую — вручную.
