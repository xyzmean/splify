# Дополнительно (расширенные настройки)

← [На главную](Home.md)

Вкладка **Дополнительно** — для тех, кому нужен полный контроль. Большинству
пользователей сюда заходить не нужно: всё необходимое есть на «Главной».

## Основное

- **Режим маршрутизации:**
  - *Через VPN только заблокированное (рекомендуется)* — через туннель идут только
    списки заблокированного/зарубежного, остальное напрямую.
  - *Всё через VPN, исключения — напрямую* — по умолчанию всё в туннель, а список
    «напрямую» — исключения.
  - *Через VPN только выбранные списки/домены* — в туннель идёт только то, что вы
    явно указали.
- **Интервал проверки (сек)** — как часто проверять туннели и переключаться при
  сбое.
- **Блокировать трафик, если туннель недоступен** (kill switch) — не выпускать
  трафик в обход VPN, когда все туннели мертвы.
- **LAN-интерфейс / подсеть**, адреса проверки связи — обычно определяются сами.

## Туннели (с приоритетом)

Список туннелей с номерами приоритета: меньший номер — выше. Если первый отвалится,
splify переключится на следующий. Здесь же выбирается **тип** туннеля
(`WireGuard / AmneziaWG`; `sing-box` — [в планах](sing-box.md)).

## Списки

URL-адреса списков заблокированных/прямых IP и доменов, переключатель **zapret**
(обход DPI). Значения по умолчанию рабочие — меняйте, только если знаете зачем.

## Ручные записи

Свои подсети и домены: что гнать через VPN, а что напрямую — вручную.

## Правила для отдельных устройств

Привязка конкретного устройства LAN (по IP) к VPN или к прямому каналу.

Полная карта команд и файлов — в [Для продвинутых](Для-продвинутых.md).
