# Простой режим (вкладка «Главная»)

← [На главную](Home.md)

Вкладка **Главная** — это всё, что нужно обычному пользователю.

## Кнопка «Включить / Выключить»

Главный переключатель. **Включить** — splify начинает направлять заблокированное
через VPN и запускается автоматически при перезагрузке роутера. **Выключить** —
весь трафик идёт напрямую.

## «Подключаться через»

Выпадающий список ваших VPN-туннелей. Выберите тот, через который хотите выходить.
Если туннелей нет, splify подскажет создать его в **Сеть → Интерфейсы**.

## Строка состояния

Цветная полоса сверху показывает, что происходит прямо сейчас (зелёная — вы под
защитой VPN). Подробности про каждое состояние — в
[Быстром старте](Быстрый-старт.md).

## Кнопки

- **Обновить списки** — принудительно скачать свежие списки заблокированного.
- **Починить автоматически** — появляется только если есть проблема с
  брандмауэром, которую splify умеет решить сам.

## «Подробное состояние»

Ссылка внизу разворачивает полный дашборд: живая скорость по каждому туннелю,
цепочка маршрутизации, диагностика и журнал переключений. Нужна редко — в
основном для отладки.

Тонкие настройки — на вкладке **[Дополнительно](Дополнительно.md)**.
