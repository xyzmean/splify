# Быстрый старт

← [На главную](Home.md)

## 1. Создайте VPN-туннель

В **Сеть → Интерфейсы** создайте интерфейс **WireGuard** или **AmneziaWG**
обычным образом (ключи и peer выдаёт ваш VPN-провайдер). splify сам ключами не
управляет — он только направляет трафик через готовый туннель.

## 2. Откройте splify

**Сервисы → splify → Главная**. Если туннель создан — он появится в списке
**«Подключаться через»**. Выберите нужный.

## 3. Включите

Нажмите большую кнопку **«Включить»**. Через несколько секунд строка состояния
станет зелёной: **«Защищено — трафик идёт через VPN»**.

## Что означает строка состояния

- 🟢 **Защищено — трафик идёт через VPN** — всё работает, заблокированное идёт
  через туннель.
- 🔴 **Прямое подключение — VPN не активен** — splify выключен или туннеля нет.
- 🔴 **Нет туннеля — работает обход DPI** — туннель недоступен, включился запасной
  обход блокировок (zapret) на прямом канале.
- 🔴 **Защита включена, но туннель недоступен — трафик заблокирован** — включён
  «kill switch», и пока туннель не поднимется, трафик не выпускается.

## Кнопки на «Главной»

- **Обновить списки** — заново скачать списки заблокированного (обычно не нужно,
  они обновляются сами раз в сутки).
- **Починить автоматически** — появляется, если splify видит проблему с
  брандмауэром, которую может исправить сам. Нажмите — и готово.
