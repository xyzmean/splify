# 🚀 splify

[![OpenWrt](https://img.shields.io/badge/OpenWrt-23.x%20%7C%2024.10%2B-blue.svg)](https://openwrt.org/)
[![Telegram Chat](https://img.shields.io/badge/Telegram-Chat-2CA5E0?style=flat&logo=telegram)](https://t.me/ssplify)

**splify** превращает ваш роутер с OpenWrt в умный VPN-шлюз. 
Заблокированные сайты идут через VPN, всё остальное — напрямую и на полной скорости. 
Никакой сложной конфигурации: настройка сводится к выполнению одной команды и пары кликов.

---

## ⚡ Быстрый старт (Установка)

Самый простой способ получить рабочий обход блокировок «из коробки» (с автонастройкой туннеля):

```sh
wget -O - https://raw.githubusercontent.com/xyzmean/splify/main/easyinstall.sh | sh
```
> **Что это делает?** 
> Скрипт установит сам `splify`, зарегистрирует устройство в Cloudflare WARP, поднимет защищённый от DPI туннель (AmneziaWG) с умным подбором быстрого эндпоинта и сразу включит нужную маршрутизацию. Вы получаете полностью рабочее решение в одну команду!

### Установка только пакета (для своего туннеля)
Если вы хотите использовать свой собственный VPN (WireGuard, OpenVPN, AmneziaWG и др.):
```sh
wget -O - https://raw.githubusercontent.com/xyzmean/splify/main/install.sh | sh
```
**Настройка после ручной установки:**
1. Создайте свой VPN-туннель в интерфейсе роутера (**Сеть → Интерфейсы**).
2. Откройте **Сервисы → splify → Главная**, выберите созданный туннель и нажмите **«Включить»**.

## 💡 Основные возможности

- 🎯 **Максимальная простота**: Включение, выключение и выбор туннеля — всё в один клик.
- 🔄 **Автоматическое обновление списков**: Адреса заблокированных ресурсов подтягиваются и обновляются сами.
- 🛡️ **Обфускация DPI**: Встроенная поддержка AmneziaWG для пробития современных систем глубокого анализа трафика.
- ♻️ **Резервирование**: Настройте запасные туннели — `splify` автоматически переключится на них при сбоях.
- 🧩 **Модульность**: Полная совместимость с пакетами обхода DPI (например, `zapret`).
- 🚀 **Sing-box**: Заложен фундамент под продвинутый роутинг (подробнее в [документации](docs/ru/sing-box.md)).
- 🎛️ **Тонкая настройка**: Kill-switch, пользовательские списки и режимы работы — на вкладке **«Дополнительно»**.
